# การเปิดใช้และตรวจรับรุ่นรับ–จ่าย

เว็บ stock ปัจจุบันเปิดด้วยลิงก์และโหลดข้อมูลทันทีโดยไม่ต้องใส่รหัสทีม; ผลตรวจรับบัญชีจริงหลังการเปลี่ยนแปลงล่าสุดยังต้องยืนยัน

ใช้ไฟล์ Google Sheet **ทดสอบแยกจากข้อมูลจริง** ก่อน สามารถใช้ไฟล์ POC เดิมได้หากไม่มี stock จริงในนั้น โค้ดใน Git ไม่มีรหัสทีมและไม่ควรใส่รหัสลงไฟล์ใด ๆ

1. ใน Apps Script โปรเจกต์ที่เชื่อมกับ clasp ตั้ง `APP_ENV=stock` และ `SPREADSHEET_ID` เป็น ID ของไฟล์ทดสอบใน Script Properties; ระบบ stock ไม่ใช้ `TEAM_ACCESS_CODE` แล้ว ค่าที่มีอยู่เดิมไม่ถูกนำมาตรวจ
2. ตั้ง timezone ของ Script และ Spreadsheet เป็น `Asia/Bangkok` โค้ดใน Git ระบุ Sheets OAuth scope แล้ว แต่ยังไม่ได้ push หรือให้บัญชีเจ้าของอนุญาตสิทธิ์ จึงยังอ่าน/เขียน Sheet จริงไม่ได้
3. Push โค้ดและเปิด Apps Script editor ในบัญชีเจ้าของ รัน `setupStock_` หนึ่งครั้งเพื่อขอสิทธิ์และสร้างหัวตาราง `Items` กับ `Movements` โดยไม่ลบข้อมูลเดิม หากแท็บมีข้อมูล/โครงสร้างไม่ตรง ระบบจะหยุดให้ตรวจ ไม่เขียนทับ
4. Deploy web app เวอร์ชันใหม่ให้ทำงานในสิทธิ์เจ้าของ แล้วทดสอบกับสอง Chrome profiles ที่ลงชื่อเข้าใช้ Google คนละบัญชี เจ้าของตรวจว่าอีกบัญชีเปิดหน้าและบันทึกผ่านเว็บได้โดยไม่มีสิทธิ์แก้ Sheet โดยตรง
5. เพิ่มอุปกรณ์ทดสอบ รับยอดเริ่มต้น 5 รับเพิ่ม 2 จ่าย 1 ตรวจยอด 6; ทดสอบจ่าย 7 ต้องไม่เพิ่มแถว; กดซ้ำ request เดิมต้องมี movement เพียงแถวเดียว ตรวจประวัติและเวลาบันทึกใน Sheet
6. กด “แก้ไข” อุปกรณ์ที่มีประวัติ แล้วกด “เพิ่มอุปกรณ์ใหม่”; กรอกรหัส/ชื่อ/หน่วยของชิ้นที่สองต่างจากเดิมและบันทึก ต้องเพิ่มเป็นอีกชนิด ไม่ขึ้นข้อความเปลี่ยนหน่วยของชิ้นแรก ตรวจ “สรุปรายงาน” ช่วงวันที่ที่มีรายการว่ารับ–จ่ายและยอดปลายช่วงตรงกับประวัติ
7. สำหรับ version 6 ใช้อุปกรณ์ทดสอบ รับเข้า 2 แล้วไปประวัติกด “กลับรายการ” ของรายการรับนั้น ใส่เหตุผลและชื่อผู้บันทึก ยอดต้องกลับเท่าเดิม ประวัติเดิมยังอยู่พร้อมสถานะ “กลับแล้ว” และมีรายการกลับใหม่หนึ่งแถว กดกลับซ้ำต้องไม่เพิ่มแถว รายงานช่วงวันนั้นต้องมียอดกลับรายการสุทธิ -2; หากรับมา 2 แล้วจ่ายออกจนเหลือไม่ถึง 2 การกลับรายการรับต้องถูกปฏิเสธ

อย่าใช้ไฟล์ทดสอบนี้กับข้อมูลคลังจริงจนกว่าจะผ่านข้อ 1–5 และตัดสินใจเรื่องการแก้รายการผิด/การสำรองข้อมูล ระบบรุ่นนี้ยังไม่มี workflow กลับรายการหรือรายงานละเอียด
