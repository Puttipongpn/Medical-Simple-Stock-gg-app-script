# ผลทดสอบบัญชีจริง — รอเจ้าของบัญชี

**ผลล่าสุดจากผู้ใช้:** standalone POC เวอร์ชัน 2 เปิดได้ใน Chrome Guest mode แต่ Chrome โปรไฟล์ที่ใช้งานอยู่ไป URL `/macros/u/1/s/.../exec` และแสดง Google Drive “ไม่สามารถเปิดไฟล์ได้ในเวลานี้” จึงยังไม่ผ่านการเปิดใช้งานด้วยโปรไฟล์ปกติ และยังไม่ได้ทดสอบสองบัญชีหรือ Google Sheets จริง รุ่นนี้เป็น preview-only เพราะ `oauthScopes: []`.

**การตรวจถัดไป:** ลอง Chrome profile ใหม่ที่มี Google login เพียงบัญชีเดียว เปิด `/exec` โดยตรง แล้วทำซ้ำกับอีกบัญชีใน profile แยก บันทึกว่าเปิดหน้าได้หรือไม่ก่อนตั้งค่า Sheet/ทดสอบเขียน อย่าใช้ Guest mode เป็นหลักฐานว่าการเข้าถึงของทีมผ่านแล้ว

**สถานะ ณ 6 ตุลาคม 2026: Deploy เวอร์ชัน 1 แล้ว แต่ยังไม่ทดสอบสองบัญชี** เปิด /exec ใน browser ที่ยังไม่ login แล้วไปหน้า Google Sign in จริง ยังรอ Script Properties / timezone Sheet / setup / consent และทดสอบ data endpoints ห้ามเติม PASS จาก local mocks

## ข้อมูล deployment (กรอกหลังทดสอบ)

- วันที่/เวลา Asia/Bangkok: ยังไม่ทดสอบ
- เวอร์ชัน deployment: 1 (ยืนยันด้วย clasp list-deployments)
- ประเภทบัญชีเจ้าของ / บัญชีที่สอง (Gmail หรือ Workspace ไม่ต้องระบุอีเมล): ยังไม่ทราบ
- Execute as ที่ตั้งใน manifest: USER_DEPLOYING; รอพิสูจน์ runtime
- Who has access: ANYONE ใน manifest (Google login required); ยังไม่ได้ดูข้อความในเมนู editor
- ใช้ `/exec` / โปรไฟล์แยก: รอทดสอบ
- Sheet ไม่แชร์ให้บัญชีที่สอง: รอทดสอบ

## การตรวจโดยผู้ดูแล

- setup ซ้ำ: ยังไม่ทดสอบ
- Script/Sheet timezone Asia/Bangkok: ยังไม่ทดสอบ
- เรียก data endpoint โดยตรงโดยไม่มีรหัส: ยังไม่ทดสอบ
- รหัสผิดไม่เพิ่มแถวและไม่เปิดเผยข้อมูล Sheet: ยังไม่ทดสอบ
- สองบัญชีกดพร้อมกัน: ยังไม่ทดสอบบน Google จริง
- บันทึก secret ใน HTML/log/Git: ต้องตรวจอีกครั้งหลังตั้งค่าจริง

## ข้อสรุปการเข้าใช้งาน

วิธีที่มีโค้ดรองรับตอนนี้: รหัสทีมตรวจที่ server; observed email เป็นผลตรวจประกอบเท่านั้น

วิธีที่เลือกใช้จริงและเหตุผล: **รอผลสองบัญชี**

ข้อจำกัดที่ยอมรับ: หากใช้รหัสทีม ชื่อ Operators ที่จะเลือกในเฟสถัดไปเป็นผู้ใช้ระบุเอง role ไม่ใช่ authorization ต้องมี credential ผู้ดูแลแยกก่อนให้สิทธิ์ admin ผ่านเว็บ

ผู้ตรวจ / วันที่ตรวจรับ / ผลผ่านหรือไม่ผ่าน: **รอเจ้าของบัญชี**
